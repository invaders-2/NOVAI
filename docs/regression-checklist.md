# 画布回归测试清单

> 用途：每次发布前手动过一遍，防止「修 A 坏 B」。画布是 NOVAI 修复最多的区域（v1.0.83~v1.0.96 一半以上改动在此），发版必测。
> 适用：无限画布（canvas.html）与智能画布（smart-canvas.html）。

## 1. 画布基础

- [ ] 新建画布 → 空白画布正常出现，网格背景渲染
- [ ] 画布拖拽平移（鼠标/触控板），松手不漂移
- [ ] 画布缩放：滚轮缩放 ±5% 固定步进，缩放中心跟随鼠标
- [ ] 缩放工具栏：适应画布 / 定位（回到 100%）/ 放大 / 缩小 / 百分比显示 / 全屏 全部可用
- [ ] 浮窗全屏模式：进入全屏、ESC 退出全屏、退出后视口位置不变
- [ ] 触摸板/触屏捏合缩放（NovaViewport 内联依赖：safeScale / viewportTransform / screenToWorld）
- [ ] 刷新页面后画布视口位置保持（localStorage 记忆）

## 2. 节点与连线

- [ ] 拖入/新建节点正常，节点拖动不卡顿
- [ ] 节点连线（startLink）不触发页面默认行为（preventDefault 生效）
- [ ] 连线渲染（renderLinks）正确：连线跟随节点移动、删除节点后连线清理
- [ ] 节点任务状态：运行中显示、完成后停止（node.running 不提前清零）
- [ ] 多任务并发：同时多个节点运行，状态互不干扰

## 3. 智能画布 Composer

- [ ] Composer 面板弹出位置正确（不超出画布可视区）
- [ ] Composer popover 不溢出裁剪（overflow: visible 生效）
- [ ] 弹窗内容完整显示（不被边栏/标题栏遮挡）
- [ ] 边栏打开/收起后 Composer 定位不偏移
- [ ] 标题栏布局：窗口缩放后控件不错位

## 4. 生成任务

- [ ] 画布内文生图：提交 → 任务队列出现 → 完成后图片落到画布
- [ ] 画布内视频任务：提交 → 轮询状态 → 完成
- [ ] 画布内 LLM 节点：提交 → 流式/完整输出到节点
- [ ] 任务失败时错误提示清晰，不白屏、不卡死
- [ ] 生成中切页/切 tab，返回后任务状态正确（rAF 暂停/恢复正常）

## 5. 画布工作台（列表页）

- [ ] 画布列表卡片显示缩略图（最多 4 张 2×2 网格）
- [ ] 打开画布 → 修改 → 返回列表，缩略图更新
- [ ] 回收站：删除画布进回收站、恢复、彻底删除
- [ ] 项目分组：创建/重命名/删除项目

## 6. 素材联动

- [ ] 素材库拖图到画布，图片进入画布
- [ ] 画布内图片保存到素材库（路径正确，走配置的素材目录）
- [ ] 共享文件夹引用素材可正常显示

## 7. 回归快检（30 秒版）

以下 5 项必测，其余按改动范围选测：

1. 缩放工具栏 5 个按钮 + 百分比显示
2. 全屏进入 + ESC 退出
3. Composer 弹出位置不裁切
4. 文生图一单任务全流程
5. 刷新页面视口保持
